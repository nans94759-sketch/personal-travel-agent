# 收费设计（commercial 分支）

> 遵循 `usd-web-venture` 里的算账框架：谁掏钱 → 凭什么非掏不可 → CAC → LTV → 为什么 ChatGPT 干不了。

---

## 一、客户是谁

**免签入境中国的外国旅客。**

不选中国出境游客，理由很直接：他们付人民币、对手是免费的 12306 和携程，收不到钱。而入境旅客有三个特点：

1. **付美元**，且对 $39 这个量级不敏感（对比人工行程定制 $100–300/单）。
2. **真的搞不定**：12306 要护照实名、支付要绑境外卡、热门景区要提前预约、高铁选座规则看不懂、地图与打车软件不通用。这不是"懒得查"，是"查了也订不上"。
3. **错误成本高**：订错票、算错换乘时间，直接毁掉一天行程。焦虑程度决定付费意愿。

---

## 二、三档定价

| 档位 | 价格 | 交付物 | 定位 |
| :-- | :-- | :-- | :-- |
| **Trip Pack** | `$39` / 单 | 一份 7–10 天 PDF 行程 + `.ics` 日历 + 1 次修订 | 主力，占收入 70% |
| **Trip Pass** | `$19` / 月 | 自助不限次查询与行程生成，无人工 | 补充，服务已在路上的旅客 |
| **Concierge** | `$149` / 单 | 人工介入 + 代订指导 + 行中 WhatsApp 答疑 | 高客单，限量，每周不超过 5 单 |

**不要做纯订阅制。** 旅行是低频行为（一年 1–3 次），订阅留存撑不住，用户第二个月就会取消并觉得被坑。主推单次付费，订阅只作为"行程进行中"的短期附加。

## 三、单位经济

| 项目 | 数值 | 说明 |
| :-- | :-- | :-- |
| 客单价 | `$39` | Trip Pack |
| 单次 LLM 成本 | `$0.002 – 0.01` | 一次完整行程约 5–15 轮对话 |
| 单次数据成本 | `$0` | 联盟接口与公开汇率接口不收费 |
| 支付通道费 | `~5% + $0.4` | Creem / Lemon Squeezy（MoR，含税务） |
| **毛利率** | **> 90%** | |

**目标拆解（月入 $2,000）**

- Trip Pack 路径：`51 单/月` ≈ 每天 1.7 单
- Concierge 路径：`14 单/月`（更省流量，但吃你的时间）
- Trip Pass 路径：`105 个在订用户`（最难，因为要持续拉新）

推荐组合：**每月 40 单 Trip Pack + 3 单 Concierge ≈ $2,000**，不需要任何广告。

## 四、CAC 与获客

零预算路径，全部是"名单可枚举"的鱼塘：

| 渠道 | 动作 | 备注 |
| :-- | :-- | :-- |
| `r/travelchina`、`r/China` | 回答"怎么订高铁/怎么用支付宝"类问题，附免费样例 | 禁止硬广，先给价值 |
| Quora | 长尾问题（"Can foreigners book China high-speed rail online?"） | 英文长文，带 SEO 价值 |
| YouTube 评论区 | 中国旅行 vlog 下回答具体问题 | 转化率高但慢 |
| 小红书 / 微信视频号 | 反向做"教外国人玩中国"的内容 | 中文内容也能触达海外华人 |

**先做免费样例，不要先做产品。** 拿 3 个真实行程（北京 5 天 / 上海+杭州 7 天 / 成都+九寨 6 天）做成 PDF，发到上面这些地方，看有没有人主动问"能不能帮我做一个"。有人问，才写付费墙。

## 五、为什么 ChatGPT 干不了

这是定价的底气，也是必须守住的边界：

1. **拿不到实时余票** —— 大模型只能编，编出来的车次和座位号是假的。
2. **算不了空铁联运** —— "杭州飞河内没直飞，上海转机 vs 杭州高铁到虹桥再飞"这种组合，需要真实时刻表求解。
3. **给不了可执行文件** —— `.ics` 日历、可打印 PDF、离线可看的行程单。
4. **不敢担保** —— 你卖的不是"一段文字"，是"我核过了，这趟车这个时间有票"。

第 4 条是护城河，也是责任来源，所以 `docs/COMPLIANCE.md` 里的免责表述必须写清楚：**实时余票参考，以出票方为准。**

## 六、收款与交付

- **通道**：Creem（个人可开、MoR、支持支付宝/微信/卡）。上线前先跑通一笔 $1 测试单。
- **交付**：付款后自动发邮件（PDF + `.ics` 附件 + 一个只读网页版链接）。
- **退款**：交付物未生成前 24 小时内全额退；已生成 PDF 的按次不退，但要给一次免费修订。
- **不做的**：不代收票款、不做资金池、不承诺出票。你卖的是信息与规划，不是旅行社业务。

---

## 七、上线前的三个数字

在写付费墙之前，先拿到这三个数，否则都是空谈：

1. **访问 → 生成行程** 的转化率（目标 ≥ 8%）
2. **生成行程 → 点"去预订"** 的转化率（目标 ≥ 25%）
3. **点预订 → 实际付费买 Trip Pack** 的转化率（目标 ≥ 3%）

第 3 个数字如果低于 1%，说明 Trip Pack 的交付物不够值 $39，要么降价，要么把交付物做厚（加餐厅预约清单、加行中答疑）。
